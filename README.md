# SBU Grade Tracker

A Python program for tracking course grades and calculating target scores.

## Features

- Calculate a student's current final grade
- Convert numerical grades into letter grades
- Calculate the exam grade needed to reach a target grade
- Check whether course weights add up to 100%
- Handle cases where the required exam grade is above 100%
- Detect when a student has already reached their target grade

## How to Use

1. Run `grade_tracker.py`
2. Enter the course name
3. Choose one of the following options:
   - Calculate your current final grade
   - Calculate the exam grade needed to reach your target grade
4. Enter your grades and their corresponding weights
5. The program will calculate the result
